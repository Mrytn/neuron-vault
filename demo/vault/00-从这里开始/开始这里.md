# 开始这里

欢迎来到棱镜展厅：一个完全虚构的互动展览设备项目。这套合成笔记用于体验本地编辑、搜索、双向链接、三维图谱和有来源的检索问答。

> **合成演示资料**：本文完全虚构，不含真实用户笔记、访谈、机构或业务数据。数字只用于说明格式与实验设计。

## 核心记录

- 先打开“演示索引”，从产品问题进入架构决策，再沿双链走到实验和复盘。每条关系都来自笔记中的真实链接或共享标签。

- 打开三维图谱，拖动旋转、滚轮缩放、点击节点查看笔记；切换标签关系可以观察不同知识簇。这里的节点并非硬编码演示点。

- 尝试编辑本篇，添加一条链接，再保存；也可把练习笔记移到回收站后恢复。操作只影响独立的演示数据副本。

- 未配置模型时，助手返回带来源的本地词法检索摘录，不会假装执行了模型推理。演示无需 API Key，也不应在公开录像中输入真实密钥。

## 如何核对

用“幂等收件箱”和“离线冲突”分别搜索，再在助手中尝试“问答练习”中的问题。

## 演示数据的边界

仓库中的 `demo/vault` 是只读种子。`./scripts/demo.sh` 把它复制到独立的 `.demo-data/vault`，再通过真实后端启动演示。默认端口为 `8790`，停止方式为终端中的 `Ctrl+C`。再次打开已有副本使用 `./scripts/demo.sh --reuse`；它不会重置你做过的练习修改。常规启动不会自动导入演示资料。
